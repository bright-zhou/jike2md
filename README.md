# jike2md

**在即刻作者主页点一下书签，把 TA 的全部动态导出为一个 Markdown 文件** —— 留存、回顾、检索，或导入 NotebookLM 等任何工具。

[立即使用 → 安装页](https://jike2md.wozai.online/)

## 为什么用它

- **安装成本接近零**：不装扩展、不进应用商店、不用命令行 —— 把按钮拖进书签栏就完成了。
- **零权限、零后台**：它不是扩展，不需要授权访问任何网站，也不常驻运行。
- **数据不出浏览器**：token 与导出内容不经任何第三方服务器，Markdown 在你本机生成。
- **全程可审计**：全部逻辑就是一个文件，安装前可在安装页当场展开逐行核对。

## 快速开始

1. 打开[安装页](https://jike2md.wozai.online/)，按引导把按钮拖进书签栏（拖不动有手动方式，效果一样）。
2. 在浏览器登录 [web.okjike.com](https://web.okjike.com/)。
3. 打开任意作者主页（地址形如 `web.okjike.com/u/…`）→ 点书签 → 浏览器自动下载 `jike-作者名-日期.md`。

以后每次使用：**打开作者主页 → 点书签 → 拿文件**。排障见安装页的常见问题。

## 导出的是什么

单个 Markdown 文件：YAML front matter（作者、ID、时间、条数）+ 按时间线排列的每条动态（正文、配图远程链接、原文链接）。转发且作者没写评论的条目，会以引用块附上被转的原文与原帖链接。

## 隐私

- **token**：取自你自己浏览器里 jike 登录态的 `localStorage`，不经过任何第三方；
- **请求**：只发往即刻官方接口 `api.ruguoapp.com`（就是你打开网页版时浏览器自己发的那一个）；
- **导出**：Markdown 在浏览器本地组装并直接下载，全程没有服务器。

## 使用边界

本工具是个人开源项目，**与即刻官方无隶属关系**。

- 请仅用于导出**你自己的内容**，或**已获作者授权**的内容；
- 导出文件的著作权归原发帖作者，请勿公开传播或用于商业用途；
- 使用本工具即表示你自行承担相关责任。

## 源码

全部逻辑就是 [`jike2md.src.js`](jike2md.src.js) 一个文件，安装页上也能展开查看。改动它之后运行 `node build.mjs` 重新生成 `index.html`。
