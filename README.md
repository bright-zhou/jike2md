# jike2md

**在即刻（jike）作者主页点一下书签，把 TA 的全部动态导出为一个 Markdown 文件** —— 留存、回顾、检索，或导入 NotebookLM 等任何工具，怎么用由你决定。

[立即使用 → 安装页](https://jike2md.vercel.app/)

无需应用商店、无需装扩展、无需命令行。一次安装，终身一键。

## 快速开始

1. 打开[安装页](https://jike2md.vercel.app/)，按页面引导把按钮拖进书签栏（拖不动有手动方式，效果一样）。
2. 在浏览器登录 [web.okjike.com](https://web.okjike.com/)。
3. 打开任意作者主页（地址形如 `web.okjike.com/u/…`）→ 点书签 → 浏览器自动下载 `jike-作者名-日期.md`。

以后每次使用：**打开作者主页 → 点书签 → 拿文件**，就这一步。

## 导出的是什么

单个 Markdown 文件：YAML front matter（作者、ID、时间、条数）+ 按时间线排列的每条动态（正文、配图远程链接、原文链接）。转发且作者没写评论的条目，会以引用块附上被转的原文与原帖链接。

## 隐私

- **token**：取自你自己浏览器里 jike 登录态的 `localStorage`，不经过任何第三方；
- **请求**：只发往即刻官方接口 `api.ruguoapp.com`（就是你打开网页版时浏览器自己发的那一个）；
- **导出**：Markdown 在浏览器本地组装并直接下载，全程没有服务器。

## 源码

全部逻辑就是 [`jike2md.src.js`](jike2md.src.js) 一个文件 —— 安装页上也能展开查看，安装前逐行检查。

想自己构建安装页（需要 Node.js 18+）：

```bash
node build.mjs   # 读取 jike2md.src.js，生成 index.html
```

## 常见问题

| 现象 | 解决 |
|---|---|
| 点书签没反应 | 只能在 `web.okjike.com` 页面上用；检查书签网址是否以 `javascript:` 开头（粘贴时前缀可能被剥掉） |
| 提示 token 无效 / 过期 | 刷新 jike 页面或重新登录后再点 |
| 条数比主页显示的少 | 确认在**该作者的主页**上点击（脚本按当前地址识别作者）；转发的条目会附上原文，不会丢条 |
